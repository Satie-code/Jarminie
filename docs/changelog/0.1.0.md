## Summary

The engineering foundation: JARMINEI is now a real, launchable PySide6 desktop application with configuration, logging, resource monitoring, and orchestration underneath it. Nothing AI-related yet — that begins at Level 2.

## What Shipped

- **Repository & environment** (1.1) — full subsystem package skeleton, dependency management, Python 3.12 venv, engineering docs archived in-repo.
- **Configuration Manager** (1.2) — typed `AppConfig` schema, `defaults.yaml` → `local.yaml` → env-var precedence, fail-loud validation.
- **Logging System** (1.3) — structured console + rotating-file logging, sensitive-data redaction.
- **Health Monitor** (1.4) — CPU/RAM/disk/battery sampling and threshold breach detection.
- **Core Manager** (1.5) — module registry, startup/shutdown sequencing, health-based restart; `main.py` is a real composition root.
- **Desktop Shell** (1.6) — a real PySide6 main window hosting Core's lifecycle.
- **Status Panel** (1.7) — live module states and resource usage, configurable refresh interval.
- **Settings Window** (1.8) — edit and persist every config section; verified to survive a real restart.
- **Debug Console** (1.9) — live, filterable, in-app log view.

## Verification

88 unit tests passing, `ruff check .` clean. Three real (non-mocked) event-loop smoke scripts exercise the actual `main.py` composition: window open/close, settings persistence across a simulated restart, and live log streaming to Debug Console. Full Level 1 acceptance pass recorded in [sprint_book/sprint_1_9.md](../sprint_book/sprint_1_9.md).

## Notable Bugs Found and Fixed During This Level

Several real integration bugs surfaced only once mocked unit tests were supplemented with tests driving real collaborators — see [backlog/technical_debt.md](../backlog/technical_debt.md) and the individual sprint reports for detail:

- `ConfigLoader.save()` writing to the wrong file when called without an explicit path.
- The `ui` config section being silently ignored on load regardless of file contents.
- Env-var overrides silently failing to type-coerce when their section was absent from loaded YAML.
- A PySide6 `QMenuBar.addMenu(str)` ownership-tracking quirk.
- Closing the main window not actually quitting the app when Debug Console was left open.
