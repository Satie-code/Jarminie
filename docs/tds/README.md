# Technical Design Documents (TDs)

One file per non-trivial sprint plan, produced during Step 4 (Planning) of [05_Claude_Development_Guide.md](../05_Claude_Development_Guide.md): files to create/modify, classes, functions, data flow, dependencies, and risks — written and reviewed *before* implementation begins. Trivial sprints (e.g. pure bootstrap/config work) can fold their plan into the sprint's entry in [sprint_book/](../sprint_book/) instead of a separate TD.
